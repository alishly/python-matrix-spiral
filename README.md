# Python Matrix Spiral

Асинхронная Python-библиотека для загрузки квадратной матрицы по HTTP/HTTPS и преобразования её элементов в список с помощью спирального обхода против часовой стрелки, начиная с верхнего левого угла.

## Исходное задание

Тестовое задание Avito:  
https://github.com/avito-tech/python-trainee-assignment

Исходный файл с матрицей:  
https://raw.githubusercontent.com/avito-tech/python-trainee-assignment/main/matrix.txt

## Реализованный функционал

- Асинхронная загрузка матрицы по URL с помощью `aiohttp`.
- Разбор текстового представления матрицы.
- Проверка корректности входных данных.
- Проверка квадратной формы матрицы.
- Спиральный обход против часовой стрелки.
- Обработка ошибок загрузки и некорректного формата данных.
- Автоматические тесты с использованием `pytest` и `aioresponses`.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/alishly/python-matrix-spiral
```

Перейти в папку проекта:

```bash
cd python-matrix-spiral
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Для запуска программы выполнить команду:

```bash
python main.py
```

Программа загрузит матрицу по указанному URL и выведет результат спирального обхода.

## Тестирование

Для запуска автоматических тестов выполнить:

```bash
pytest -v
```

Тестами проверяются:

- Разбор матрицы.
- Спиральный обход матрицы 4×4.
- Обработка матрицы 1×1.
- Обработка пустой матрицы.
- Обработка неквадратной матрицы.
- Обработка некорректных данных.
- Асинхронная загрузка матрицы.
- Обработка HTTP-ошибок.

Все тесты успешно пройдены.
